Overview 
Vehicle Rental Service System
Description 
In this assignment, students are required to build a professional Vehicle  Rental Service System with implementation of object-oriented  programming (OOP) principles using Java programming language. You are  required to develop a simulated environment where output can be a console  output of characters or graphical user interface (GUI). However, both  display methods are acceptable without any mark discrimination.  
It is important to note that all students’ team ideas must be different and unique from other student teams. You can innovate by having different  features and functionality. However, the following functions should be  included in your system: 
● Add/register new customers 
● Add new vehicles to the system




Deliverables 
The following items are to be handed in: 
Initial Stage (Dateline – 1 August 2025, Week 6)  
● A cover page.  
● A description of your team’s assignment idea.  
● A description of the modules that are handled by each member.  ● A draft UML class diagram that illustrates the entity classes and their  relationships. 
Final Report (Dateline – 12 Sept 2025, Week 12)  
● Initial stage report (amended version). 
● Peer evaluation forms. 
● Sample screen shots and reports/listings with brief explanation. ● OOP principles with clear explanations and include relevant code  screenshots. 
● Java project source code in the softcopy submission (Google Classroom).  Include ALL your source code files and all pre-compiled classes. ● Final UML class diagram. 
● Display available vehicles 
● Rent a vehicle to a customer 
● Return a rented vehicle 
● Calculate and display rental charges 
● Rental history 
Your application is represented as Java objects in your system. You need to  define the classes for these objects with advanced object-oriented  programming features such as polymorphism, inheritance, and  encapsulation to control and manage the objects in your system. Also, you  are encouraged to use Java’s interface to establish weak relationships  between objects in your system. 
Each student needs to be involved in system development. The students are  highly encouraged to do their own research to find more information. 
Do not use copyrighted images for your display if you are going for GUI  display. You can create your own images or use publicly available licensed  (e.g., creative common images) images with proper citation of the original  source of the image.
